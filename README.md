# Gold Analysis Platform

نظام متكامل لتحليل الذهب يتيح متابعة الأسعار، تحليل الاتجاهات، التنبؤات، التنبيهات، والتقارير.

## التقنيات المقترحة

- Frontend: Next.js + Tailwind CSS
- Backend: FastAPI / Node.js
- Database: PostgreSQL
- Cache: Redis
- ML: Python + Pandas + NumPy + PropheT / XGBoost
- Deployment: Docker + VPS / Render / Railway / Azure
